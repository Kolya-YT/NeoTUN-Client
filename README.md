# NeoTUN

NeoTUN — клиент для подключения к прокси-серверам на Android и Windows. Проект развивается: часть функций уже реализована, сетевой движок и маршрутизация продолжают проходить проверку.

- **Скачать:** [последний релиз](https://github.com/Kolya-YT/NeoTUN-Client/releases/latest)
- **Сборки:** [GitHub Actions](https://github.com/Kolya-YT/NeoTUN-Client/actions)
- **Ошибки и предложения:** [Issues](https://github.com/Kolya-YT/NeoTUN-Client/issues)

## Загрузка

### Android

Откройте [последний релиз](https://github.com/Kolya-YT/NeoTUN-Client/releases/latest) и скачайте APK для архитектуры устройства.

| Файл | Для каких устройств |
| --- | --- |
| `NeoTUN-arm64-v8a.apk` | Большинство современных Android-смартфонов и планшетов |
| `NeoTUN-armeabi-v7a.apk` | Устройства с 32-битным ARM-процессором |
| `NeoTUN-x86_64.apk` | Совместимые x86-64 устройства и эмуляторы |

Если в релизе нет APK, откройте [сборки Android](https://github.com/Kolya-YT/NeoTUN-Client/actions/workflows/android.yml), выберите успешный запуск и найдите файлы в разделе **Artifacts**. Для скачивания артефактов может понадобиться войти в GitHub.

### Windows 10/11, x64

Для установки используйте **`NeoTUN-Setup-x64.exe`** из [последнего релиза](https://github.com/Kolya-YT/NeoTUN-Client/releases/latest). ZIP-архив не является основным установочным пакетом.

1. Скачайте EXE и запустите его.
2. Подтвердите запрос контроля учётных записей Windows, если он появится.
3. Завершите установку и запустите NeoTUN из меню «Пуск».

Если установщика нет в релизе, проверьте [сборки Windows](https://github.com/Kolya-YT/NeoTUN-Client/actions/workflows/desktop.yml). В успешном запуске установщик находится в **Artifacts**. Артефакты CI хранятся ограниченное время.

## Что уже работает

Ниже перечислены реализованные части проекта и проверки, которые можно подтвердить автоматически. Это не означает, что каждый протокол и каждый сетевой сценарий уже проверен на реальном устройстве.

### Android

- Проект собирает APK для ARM64, ARMv7 и x86-64.
- В CI собираются общий Rust Core и нативная интеграция Xray.
- В приложении есть импорт профилей, настройки маршрутизации и журнал диагностики.
- В журнале на реальном устройстве подтверждались успешные DNS-ответы и передача HTTPS-соединений в outbound Hysteria2. Это подтверждает работу отдельных участков соединения, но не заменяет полную проверку всего трафика.

### Windows

- Реализован интерфейс WPF с разделами приложения, серверами, маршрутизацией, настройками и журналом.
- Реализованы локальное хранение профилей, выбор, поиск, редактирование, копирование и удаление профилей.
- Добавлен разбор ссылок VLESS, VMess, Trojan, Shadowsocks, Hysteria2 и TUIC, включая списки ссылок в Base64.
- CI собирает Windows-приложение, общий Rust Core, сетевые компоненты и установщик `NeoTUN-Setup-x64.exe`.

Успешная сборка означает, что соответствующие компоненты скомпилировались и прошли проверки workflow. Она сама по себе не подтверждает полноценную работу сетевого подключения.

## Что ещё в разработке

- **Windows TUN и маршруты:** полный жизненный цикл подключения, корректный запуск и остановка движков, DNS, восстановление сети после отключения.
- **Проверка трафика Windows:** реальные TCP- и UDP-соединения, переподключение, сон и пробуждение системы, очистка маршрутов после выхода.
- **Маршрутизация:** применение всех пользовательских правил в соответствии с выбранным порядком и проверка на каждом движке.
- **GeoSite и GeoIP:** совместимость форматов геобаз Xray и sing-box и корректное применение загруженных наборов правил.
- **Совместимость протоколов:** проверка разных транспортов и параметров подписок на реальных серверах. Поддержка формата ссылки ещё не гарантирует поддержку всех её параметров.
- **Обновление приложения:** проверка обновления поверх установленной версии, проверки целостности и корректного восстановления после ошибки.
- **Публикация релизов:** единый выпуск с APK для Android и EXE-установщиком для Windows.

Пункты выше не следует считать завершёнными, пока соответствующие проверки не пройдены.

## Исправление зависания при запуске

В версии 0.8.3 запуск sing-box вынесен в фоновый поток. Если удалённые наборы правил GeoSite/GeoIP загружаются медленно, интерфейс приложения должен оставаться отзывчивым, а не зависать на главном потоке. Первая загрузка правил всё ещё может задержать готовность соединения.

## Если соединение не работает

1. Откройте диагностику и проверьте сообщения запуска движка.
2. Убедитесь, что DNS-запросы получают ответы.
3. Проверьте доступность нескольких сайтов и приложений.
4. Если проблема сохраняется, приложите журнал и укажите протокол, устройство и версию приложения.
5. После отключения убедитесь, что системный индикатор VPN исчез и обычное подключение восстановилось.

Перед отправкой журнала удалите UUID, пароли, токены, приватные ссылки подписок и другие данные доступа.

## Сборка из исходников

### Android

Для сборки используются JDK 17, Android SDK/NDK, Rust stable, `cargo-ndk`, Go и Gradle. Настройки CI находятся в [`.github/workflows/android.yml`](.github/workflows/android.yml). Для публикации APK нужны настроенные секреты подписи.

### Windows

Нужны Windows x64, .NET 8 SDK, Rust stable с target `x86_64-pc-windows-msvc`, Visual Studio Build Tools с компонентами C++ и Inno Setup 6.

Основные команды для сборки приложения:

```powershell
rustup target add x86_64-pc-windows-msvc
cargo test --manifest-path core/Cargo.toml
cargo build --manifest-path core/Cargo.toml --release --target x86_64-pc-windows-msvc
dotnet restore windows/NeoTUN.Windows/NeoTUN.Windows.csproj
dotnet publish windows/NeoTUN.Windows/NeoTUN.Windows.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o dist/NeoTUN-Windows
```

Для полноценного установочного пакета также требуются сетевые движки и Wintun. Подробности подготовки и упаковки находятся в [workflow Windows](.github/workflows/desktop.yml) и [сценарии установщика](installer/NeoTUN-Windows.iss).

## Структура репозитория

- `android/` — Android-приложение и VPN-сервис.
- `core/` — общий Rust Core.
- `xraybridge/` — интеграция Xray для Android.
- `windows/NeoTUN.Windows/` — Windows-клиент.
- `installer/` — сценарий установщика Windows.
- `.github/workflows/` — автоматическая сборка и публикация.

NeoTUN находится в разработке. Перед установкой новой версии проверяйте статус сборки и состав файлов в релизе.
